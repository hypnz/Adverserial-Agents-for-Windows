# Changelog

## 2.0.0

- Added launch plans for Claude Code, Codex, OpenCode, Pi, Oh My Pi, Kimi Code,
  ZCode and DeepSeek Harness alongside the dedicated Hermes adapter.
- Added isolated agent profiles, inventory and per-agent doctor checks.
- Added a native attestation console wrapper for Pi/OMP on Windows.
- Kept the shared fresh-verification gate and owned gateway/token lifecycle.
- Added English agent documentation and new-PC migration instructions.
- Packaged a GitHub repository with Windows/Linux fixture CI, draft releases,
  source ZIP/checksum builder, contribution/security docs and licensing notices.
